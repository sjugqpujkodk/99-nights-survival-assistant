## Overview

99 Nights in the Forest Survival Assistant is a companion app for the survival game 99 Nights in the Forest, providing a day-by-day resource consumption calculator, shelter upgrade priority guide, food spoilage timer, and a threat calendar that predicts when the game's escalating dangers peak — helping players plan their survival strategy across the game's 99-day cycle.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **99 Nights in the Forest Survival Assistant** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resource Calculator** | Projects resource consumption across upcoming in-game days |
| **Shelter Planner** | Upgrade priority guide based on current day and available resources |
| **Food Timer** | Tracks spoilage timers for gathered food items to minimize waste |
| **Threat Calendar** | Predicts escalating threat cycles to help plan defensive preparation |
